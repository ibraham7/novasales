# تشغيل الحملات

تطبيق ترحيل `20261002214655_restore_campaign_engine.sql` مطلوب قبل استخدام القوالب والحملات. الجداول الأربعة متاحة للسيرفر فقط مع RLS؛ جميع إجراءات المستخدم تمر عبر فحص صلاحيات المؤسسة.

- `cmp.campaigns.manage`: إنشاء وتعديل المسودات والقوالب وحذف الحملات غير النشطة.
- `cmp.campaigns.send`: إطلاق وإيقاف واستئناف وإلغاء ومعالجة الحملات.
- لا يُرسل حفظ المسودة رسائل. إطلاقها يجعلها مجدولة. زر **معالجة الحملات الجاهزة** يعالج المؤسسة الحالية فقط وقد يرسل رسائل حقيقية.
- زر **اعتماد الموعد** يحترم تاريخ الإطلاق المستقبلي. زر **إطلاق** يحدد الوقت الحالي.
- تدعم قوالب الحملات النص ومتغير `{{name}}`. إرسال وسائط القالب غير مدعوم في هذه الواجهة.
- الجمهور يدعم المرحلة والقسم وحالة العميل المحتمل والعملاء المحددين عبر السيرفر. فلترة الوسوم غير متاحة لأن جداول وسوم جهات الاتصال غير موجودة؛ يُرفض طلبها برسالة واضحة.
- الحجز يحد التشغيل إلى دفعة في الدقيقة لكل حملة ويمنع عاملين من أخذ الرسالة نفسها. الرسائل التي بقيت بحالة الإرسال بعد انقطاع التنفيذ تُعلّم فاشلة بعد عشر دقائق؛ يجب التحقق من واتساب قبل إعادة إرسالها، لتجنب التكرار. هذا لا يضمن exactly-once لدى مزود واتساب الخارجي.
- لا تُنشأ مهمة دورية تلقائيًا. لإعدادها، خزّن سرًا عشوائيًا لا يقل عن 32 محرفًا باسم `CAMPAIGN_CRON_TOKEN` في Worker. استخدم جدولة خارجية ترسل POST كل دقيقة إلى `/api/public/cmp-tick` مع `Authorization: Bearer <token>`؛ الطلب دون رمز صحيح مرفوض.
- الاختبارات المحلية لا ترسل رسائل واتساب ولا تنشئ بيانات اختبار على Supabase الإنتاجي.
