# إضافة المنتج مع خصائصه ومخزونه

من «إضافة منتج» أدخل البيانات والسعر والعملة، وعرّف خصائص المؤسسة أو اختر الخصائص المناسبة للمنتج. خصائص المنتج مثل سعر التكلفة لا تفصل الكمية. خصائص خيارات المخزون مثل المقاس واللون تفصلها.

داخل «خيارات المنتج والكميات والدفعات» أضف تركيبة لكل مجموعة قيم (خمري / M ثم خمري / L). أضف إلى كل تركيبة دفعة أو أكثر، مع رقم مستقل وكمية موجبة وتاريخ انتهاء اختياري. استخدم اختيارًا واحدًا للمقاس إذا كان لكل مقاس كمية مختلفة. الاختيار المتعدد يصف تركيبة واحدة، ولا يوزع كميتها تلقائيًا على الخيارات.

يحتاج إدخال الكميات إلى صلاحية inventory.manage، إضافة إلى products.manage. يمكن إنشاء منتج أو خدمة دون مخزون أولي.

حفظ المنتج الجديد يستخدم الدالة create_sales_product_with_stock في معاملة واحدة لإنشاء المنتج والتركيبات والدفعات وحركات المخزون. أي خطأ يلغي المعاملة كاملة. تعريفات خصائص المؤسسة تُحفظ بصورة مستقلة وتبقى قابلة لإعادة الاستخدام. تعديل مخزون منتج قائم يبقى من نافذة خيارات المخزون والدفعات، لحماية كمياته وسجلاته السابقة.
